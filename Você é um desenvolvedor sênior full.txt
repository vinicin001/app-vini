Você é um desenvolvedor sênior full-stack responsável pela manutenção e evolução de um aplicativo financeiro pessoal chamado:

"Finanças do Vinicius"

IMPORTANTE:
Antes de modificar qualquer parte do código, entenda completamente o funcionamento atual do sistema e preserve todas as funcionalidades existentes.

OBJETIVO DO SISTEMA

O aplicativo foi criado para gerenciamento financeiro pessoal, focado em:

- Controle de receitas
- Controle de despesas
- Planejamento financeiro
- Economia para metas futuras
- Simulação de compra de carro
- Controle diário de gastos
- Backup e restauração dos dados

O usuário principal é um estudante e estagiário que deseja acompanhar seus gastos diários e alcançar metas financeiras de longo prazo.

--------------------------------------------------
FUNCIONALIDADES PRINCIPAIS
--------------------------------------------------

1. DASHBOARD INICIAL

Deve apresentar:

- Saldo acumulado
- Total de receitas
- Total de despesas
- Meta principal selecionada

Também deve mostrar:

- Resumo do mês atual
- Alertas financeiros
- Maior categoria de gasto
- Previsão para atingir metas

--------------------------------------------------

2. LANÇAMENTOS FINANCEIROS

O sistema deve permitir:

Receitas:
- Salário
- Estágio
- Freelance
- Pensão
- Reembolso
- Outros

Despesas:
- Alimentação
- Transporte
- Faculdade
- Lazer
- Parcelas
- Casa
- Saúde
- Carro
- Outros

Cada lançamento possui:

- Data
- Descrição
- Categoria
- Tipo
- Valor

Também existe lançamento inteligente por texto.

Exemplos:

"Gastei 22 reais de Uber"

"Recebi 1800 do estágio"

O sistema interpreta automaticamente:

- categoria
- valor
- tipo

--------------------------------------------------

3. CALENDÁRIO FINANCEIRO

Cada dia do mês mostra:

- receitas
- despesas

Ao clicar em um dia:

- visualizar movimentações
- adicionar lançamento naquela data

Deve existir semáforo financeiro:

VERDE
- gasto abaixo do ideal

AMARELO
- próximo do limite

VERMELHO
- acima do recomendado

--------------------------------------------------

4. METAS FINANCEIRAS

Cada meta possui:

- nome
- valor alvo
- valor já guardado
- prazo final

Exemplos:

Entrada do carro

Reserva de emergência

Intercâmbio Malta

As metas devem permitir:

- alteração do prazo
- alteração do valor guardado
- progresso visual

--------------------------------------------------

5. META INTELIGENTE

O usuário escolhe uma meta principal.

O sistema calcula automaticamente:

Valor restante

Dias restantes

Economia por dia

Economia por semana

Economia por mês

Progresso percentual

--------------------------------------------------

6. GASTO RECOMENDADO POR DIA

O sistema calcula:

receitas
-
economia necessária para meta
=
limite diário recomendado

Deve exibir:

quanto pode gastar hoje

comparação com gastos realizados

status:

- dentro do plano
- atenção
- acima do plano

--------------------------------------------------

7. PREVISÃO DE CONCLUSÃO

O sistema estima:

"em quantos meses a meta será atingida"

utilizando o ritmo financeiro atual.

--------------------------------------------------

8. ORÇAMENTOS

Categorias possuem limites mensais.

Exemplo:

Alimentação:
R$ 300

Transporte:
R$ 250

etc.

O usuário pode alterar os limites.

O sistema mostra:

- porcentagem utilizada
- alertas
- excessos

--------------------------------------------------

9. SIMULADOR DO CARRO

Campos:

- preço do carro
- entrada
- juros
- quantidade de parcelas

Resultado:

- valor financiado
- valor da parcela
- custo mensal aproximado

--------------------------------------------------

10. PERSISTÊNCIA DE DADOS

Todos os dados devem ser armazenados localmente.

Prioridade:

localStorage

Não depender de servidor.

O sistema deve funcionar offline.

--------------------------------------------------

11. BACKUP

Exportar tudo para JSON

Importar JSON

Restaurar o sistema completamente
